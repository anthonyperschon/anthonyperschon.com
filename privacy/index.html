Privacy

Last updated 12 November 2026

This page covers brand-engine-mail, a private tool that Anthony Perschon Fitness LLC uses to run its own email and files. It is not offered to the public. The only Google accounts that sign in to it belong to Anthony Perschon.

What it reads

  • Gmail: it reads, sorts and labels mail in Anthony's own inboxes. It drafts and sends replies only when Anthony approves them. It keeps one signature and the inbox filters up to date.
  • Google Drive: it lists, copies and organizes the company's own files and folders.
  • YouTube: it reads view counts and analytics for Anthony's own channel, so his numbers stay current.

What it does with it

The data is used only to run the company's own mail, files and reporting. Sign-in tokens are stored on the company's own computer, never in shared files. Copies of messages are kept only as long as the work needs them.

Nothing is sold or shared

No data from these accounts is sold, rented or shared with anyone. It is not used for advertising, and it is not used to train AI models. This tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions. Once access is withdrawn, the tool stops working and its stored token is deleted.
